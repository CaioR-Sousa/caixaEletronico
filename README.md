# 🏦 Simulador de Caixa Eletrônico

Simulador de caixa eletrônico desenvolvido com **HTML, CSS e JavaScript**, com o objetivo de praticar lógica de programação, estruturas condicionais, manipulação do DOM e operações matemáticas.

## 🚀 Funcionalidades

* 💰 Consulta de saldo
* 💵 Realização de saques
* ➕ Depósitos
* 🔄 Atualização do saldo em tempo real
* ⚠️ Validação de valores informados
* 🧮 Processamento das operações através de JavaScript
* 🖥️ Interface simples e intuitiva

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript

## 📚 Conceitos praticados

Durante o desenvolvimento do projeto foram praticados conceitos importantes de JavaScript, como:

* Variáveis
* `if` / `else`
* Funções
* Operadores matemáticos
* Manipulação do DOM
* Eventos
* Validação de dados
* Controle de fluxo

## 🎯 Objetivo

O projeto foi desenvolvido como parte dos estudos de **JavaScript e lógica de programação**, buscando transformar conceitos teóricos em uma aplicação prática.


## 📌 Próximos passos

Possíveis melhorias para versões futuras:

* Sistema de senha para acesso
* Histórico de transações
* Diferentes opções de notas disponíveis para saque
* Limite diário de saque
